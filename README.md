# Machine Learning for Predicting Student Academic Outcomes

## Overview

This repository contains the code used for the Case Studies in Data Science assignment at RMIT University.

The project investigates the use of machine learning to identify factors associated with student academic outcomes using two publicly available educational datasets. Two machine learning algorithms, Random Forest and Logistic Regression, were applied to the datasets and evaluated using accuracy, precision, recall and F1-score.

## Datasets

### 1. UCI Student Performance Dataset

The UCI Student Performance Dataset contains information about student demographics, family background, study habits, attendance and academic performance.

Dataset source:  
https://archive.ics.uci.edu/dataset/320/student+performance

### 2. Open University Learning Analytics Dataset (OULAD)

The Open University Learning Analytics Dataset (OULAD) contains information about student demographics, courses, assessments and online learning activity.

Dataset source:  
https://www.kaggle.com/datasets/anlgrbz/student-demographics-online-education-dataoulad

The datasets are not included in this repository because they are publicly available from their respective sources and the OULAD dataset is relatively large.

## Machine Learning Models

The following models were used:

- Random Forest
- Logistic Regression

The models were applied separately to each dataset to identify patterns associated with student academic outcomes.

## Evaluation

Model performance was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score

Recall and F1-score were given particular consideration because the case study focuses on identifying students who may be at risk of unsuccessful academic outcomes.

## Repository Contents

- `Student_Academic_Outcomes.ipynb` – Google Colab/Jupyter Notebook containing the data processing, machine learning models, evaluation and results.
